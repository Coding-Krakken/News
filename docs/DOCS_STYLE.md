Docs Style & Templates

Purpose
- Provide consistent documentation templates and writing rules for developer-facing docs.

Rules
- Use present-tense, active voice and concise bullet lists.
- Include a one-line summary at the top, a Quick Start, and a Troubleshooting section.
- File layout: short intro, commands, examples, verification, links to related docs.

Templates
- Quick-start snippet (small copy/paste commands)
- Full example request/response for APIs

Linting
- Use `markdownlint` in CI for doc style checks and link validation.
